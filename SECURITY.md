# Security Policy

## Reporting a security issue

Do not publish a suspected security issue with WinCare Toolkit as a public GitHub issue if it could expose a destructive command path or unsafe behavior before it is reviewed.

When reporting a problem, include:

- WinCare Toolkit version
- Windows version
- The menu option or launcher used
- Relevant sanitized log output
- Expected behavior
- Actual behavior

Remove usernames, IP addresses, file paths containing personal information, and other sensitive data before sharing logs publicly.

## Safety expectations

Changes that make cleanup, repair, networking, or restart behavior more aggressive should be treated as security-sensitive changes and tested separately before release.
